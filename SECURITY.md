# Security Policy

## Supported Versions

The latest published release of this repository receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, **please do not open a public issue.**

Instead, report it privately:

* Use GitHub's private vulnerability reporting (Security -> Report a vulnerability), or
* Contact the maintainer directly and mark the message confidential.

We will acknowledge receipt within 3 business days and aim to provide a
remediation plan within 14 days. Credit will be given to reporters who wish to
be acknowledged.

> Note: These skills process personal documents locally. No data is transmitted
> to third parties by the skill itself; always review any external integration
> before use.
